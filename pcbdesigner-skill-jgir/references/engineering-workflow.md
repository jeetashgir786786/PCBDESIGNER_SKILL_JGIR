# Engineering workflow and requirements

## Requirements intake
Record purpose, inputs, outputs, electrical ranges, load profiles, accuracy, interfaces, protection, environment, enclosure, dimensions, mounting, cost, production quantity, assembly method, test access, and fabrication constraints.

## Requirement quality
Each requirement should be measurable, have an identifier, source, verification method, and acceptance criterion. Distinguish must-have from nice-to-have.

## Design reviews
- Architecture review: function, domains, risks, alternatives.
- Schematic review: connectivity, ratings, protection, testability.
- Layout review: current loops, placement, return paths, thermal, mechanical, EMI.
- Release review: DRC/ERC, output completeness, documentation, revision traceability.

## Risk
Use a simple risk register with severity, likelihood, detectability, mitigation, owner, and status. Prioritize hazards and single-point failures.
